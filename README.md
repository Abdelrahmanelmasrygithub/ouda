# موقع خطة تطوير شركة عودة

موقع React (Vite + Framer Motion) بتصميم عربي RTL، بحلقة خطوات بتترسم مع السكرول.

## التشغيل

```bash
npm install
npm run dev
```

هيفتح المتصفح تلقائيًا على `http://localhost:5173`.

للبناء النهائي: `npm run build` ثم `npm run preview`.

## التعديل

| عايز تعدّل إيه | روح فين |
| --- | --- |
| الخطوات والتفاصيل وكل النصوص | `src/data/plan.js` |
| اللوجو | ضع الملف في `public/logo.png` (أو غيّر `logoSrc` في `plan.js`) |
| الألوان | المتغيرات في أول ملف `src/styles.css` (`--primary` و`--primary-2` و`--accent`) |

- عدد الخطوات مفتوح: أضف أو احذف عناصر من `steps` والحلقة بتتظبط لوحدها.
- لو ملف اللوجو مش موجود، بيظهر لوجو نصي مؤقت تلقائيًا.
- لو لوجوك صورة من غير اسم الشركة، خلّي `showNameWithLogo: true`.
