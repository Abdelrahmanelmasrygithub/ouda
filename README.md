# موقع خطة تطوير شركة عودة

موقع React (Vite + Framer Motion) بتصميم عربي RTL: حلقة خطوات بتترسم مع السكرول، وبطاقات للخطوات بتتحمّل النصوص الطويلة.

## التشغيل

```bash
npm install
npm run dev
```

هيفتح المتصفح تلقائيًا على `http://localhost:5173`.
للبناء النهائي: `npm run build` ثم `npm run preview`.

## التعديل

| عايز تعدّل إيه | روح فين |
| --- | --- |
| الخطوات والنصوص والعناوين | `src/data/plan.js` |
| صور الخطوات | ضعها في `src/assets/images/` (الأسماء الحالية: `trend-1` و`show-1` و`show-2`) |
| اللوجو | ضعه في `src/assets/` باسم `logo.png` (أو svg/jpg/webp) |
| الألوان | المتغيرات في أول ملف `src/styles.css` (`--primary` و`--primary-2` و`--accent`) |

### الصور
- اكتب اسم الملف من غير امتداد في حقل `images` للخطوة، والموقع يلتقطه بأي امتداد (jpg/png/webp…).
- لو الصورة مش موجودة، بيظهر مكان فاضي مؤقت مكتوب عليه اسم الملف المطلوب.
- لإضافة عنوان تحت الصورة: `{ file: "trend-1", caption: "وصف الصورة" }`.
- الضغط على أي صورة يكبّرها.
- لإزالة مكان صورة من خطوة، شيل العنصر من `images` (أو خليها `images: []`).

### الخطوات
- كل خطوة: `title` و`tag` (الاسم الإنجليزي) و`short` (اسم مختصر للحلقة) و`points` (كل نقطة: `head` عنوان قصير + `text` النص).
- `goal` صندوق الهدف (اختياري)، و`note` ملحوظة (اختياري)، و`final: true` للخطوة المحورية الأخيرة.
- عدد الخطوات مفتوح، والحلقة بتتظبط لوحدها.
- لو لوجوك صورة من غير اسم الشركة، خلّي `showNameWithLogo: true` في `company`.
